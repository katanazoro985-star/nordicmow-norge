# NordicMow Norge AS - Helautomatiske Robotgressklippere

En eksklusiv, lynrask og moderne e-handelsplattform for autonome robotgressklippere i Norge.

## 🌟 Oppfylte Spesifikasjoner
1. **10 Uavhengige Robotgressklippere**:
   - Ingen ekte merkevarenavn (Gardena, Husqvarna, Worx o.l. er bevisst utelatt).
   - Premium fiktive nordiske modeller (f.eks. *TerraMow Nordic 500*, *FjordTrim Alpine 4x4 AWD*, *SylvaBot Stealth 800*, *AeroLawn Matrix 1200*, *Kjølen Master 3000*, etc.).
2. **Norske Priser (NOK)**:
   - Alle priser slutter på rene tall som **20, 30, 50 eller 00** (f.eks. `6 420 kr`, `11 930 kr`, `15 420 kr`, `26 850 kr`, `34 500 kr`). Ingen priser slutter på `.99`.
3. **Norsk Levering & Standard Leveringstid**:
   - Standard leveringstid: **2–4 virkedager** med **Posten / Bring** fra sentrallager i Oslo.
   - Beregning av dynamiske leveringsdatoer.
4. **Norsk Bedriftsadresse & Informasjon**:
   - **Foretak:** NordicMow Norge AS
   - **Org.nr:** NO 928 471 635 MVA
   - **Adresse:** Storgata 32, 0184 Oslo, Norge
   - **Telefon:** +47 21 00 45 60
   - **E-post:** kontakt@nordicmow.no
5. **Design & Brukeropplevelse**:
   - Skandinavisk luksuriøst formspråk med mørk furugrønn (`#0B1E16`), skogsgrønn (`#0F382A`) og lysende smaragdfargede detaljer (`#10B981`).
   - Interaktiv handlekurv med automatisk MVA- og fraktberegning.
   - Filtrering etter plenstørrelse ($m^2$), stigningsevne, kablefri RTK/LiDAR-navigasjon og fritekstsøk.
   - Interaktiv plen-veileder (quiz/kalkulator).
   - Norsk kasse (Checkout) med Vipps, Klarna og kortbetaling.
